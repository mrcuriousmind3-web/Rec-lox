# Contributing to Rec-lox

Thanks for taking an interest in Rec-lox.

## Before opening an issue

- Check whether the issue already exists.
- Include your Windows version, display resolution, and exact steps to reproduce.
- For recording failures, include the error code shown by Rec-lox.
- Never attach private recordings unless you intend to share them publicly.

## Pull requests

- Keep the native app lightweight and avoid adding heavyweight runtimes.
- Test a Release build on Windows 10 or Windows 11.
- Explain user-visible changes and any new dependencies.
- Keep the README and website accurate, especially regarding supported capture features.
