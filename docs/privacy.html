Privacy & transparency

Privacy Policy

Effective date: October 30, 2026

1. About Rec-lox

Rec-lox is an unofficial, open-source Windows screen-recording application intended for recording gameplay and other activity displayed on your primary monitor. It is not affiliated with, endorsed by, or operated by Roblox Corporation.

2. Recordings stay on your device

Rec-lox captures the primary display and writes video files to a local folder on your Windows device, normally Videos\\Rec-lox. The application does not include a feature to upload, transmit, or share your recordings. You choose whether and where to move or publish the files.

The current version captures video and the mouse cursor. It does not record microphone, game, or system audio.

3. Information collected by the desktop application

The current Rec-lox desktop application does not require an account, does not ask for personal information, and does not include analytics, advertising, telemetry, or an automatic update-checking service. It does not intentionally send your screen contents, recordings, or recording filenames to Rec-lox project operators.

The application uses Windows APIs, including Windows Media Foundation, to capture the display and encode video locally. Windows itself may process diagnostic or system information under your Windows privacy settings and Microsoft's own policies.

4. Website and download links

The Rec-lox website is a static site hosted by GitHub Pages. Its download menu requests public release information from the GitHub API to display the latest available installer and portable package. When you visit the website or follow a download link, GitHub may process technical information such as IP address, browser information, and request logs under its own privacy policy.

The website does not provide a Rec-lox account, advertising, or a form for submitting personal data. Links to GitHub, Roblox, and other external services are governed by the privacy policies of those services.

GitHub Privacy Statement: docs.github.com/en/site-policy/privacy-policies/github-privacy-statement.

5. Data retention and control

Recording files remain on your device until you move or delete them. Rec-lox does not maintain a remote copy. You control local recordings through Windows File Explorer.

6. Children's privacy

Rec-lox does not knowingly collect personal information from children or other users. Because the application does not require an account or provide a personal-data submission feature, there is no user profile maintained by the project.

7. Security

Rec-lox is provided as open-source software so its code can be inspected. No software can be guaranteed to be completely secure. Download releases only from the official project repository and review the source code or build the application yourself if you prefer.

8. Changes to this policy

This policy may be updated when the application's features or data practices change. The effective date at the top of this page will be updated when a revised policy is published. Check this page periodically.

9. Contact

For privacy questions or concerns, please open an issue in the official Rec-lox GitHub repository. Do not include private recordings or sensitive personal information in a public issue.

Plain-language summary: Rec-lox saves screen recordings locally on your PC. The application does not upload recordings or include app telemetry. The website uses GitHub to host its pages and to retrieve public release information.
